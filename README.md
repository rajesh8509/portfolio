# Portfolio (Next.js + Tailwind + Framer Motion)

    npm install
    npm run dev      # http://localhost:3000

- Edit all content at the top of `components/Portfolio.tsx` (name, bio, skills, jobs, projects, contact).
- Your CV (`public/cv.pdf`) and photo (`public/profile.jpg`) are already included. Update LinkedIn/GitHub links at the top of `components/Portfolio.tsx`.
- Toggle dark/white theme with the button in the navbar.
- Deploy free on Vercel: push to GitHub and import the repo.
